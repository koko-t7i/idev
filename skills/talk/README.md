# talk

`talk` 用于把尚未说清或尚未定下的问题聊到可以继续行动。它会帮助明确目标与限制，必要时核实事实、比较选项，最后给出清楚的结论和下一步。

可以用它澄清需求、选择产品或工具、讨论某件事该怎么做。用户要求完成改动时，确认理解后继续执行，不停在建议阶段。

新任务先简短确认理解。正式回复优先呈现结论和决定性依据，控制一次交给用户的信息量；详细资料按需展开。

AI 的执行规则在 [SKILL.md](SKILL.md)。以下资料按任务需要加载：

- [research.md](references/research.md)：事实核实与来源选择。
- [comparison.md](references/comparison.md)：选项筛选与比较。

## 安装

将本目录软链到 Codex 的 skills 目录即可。
